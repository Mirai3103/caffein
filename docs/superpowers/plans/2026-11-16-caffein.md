# Caffein Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Một exe Rust thuần Win32 (~300 KB) có icon khay giúp giữ Windows thức, kèm hẹn giờ và cửa sổ Settings.

**Architecture:** Một process, một luồng UI, chạy vòng lặp message Win32. Phần logic thuần (config, trạng thái/hẹn giờ, cờ execution state) tách riêng thành module có unit test. Phần Win32 (khay, menu, icon, settings, registry) là lớp mỏng gọi vào logic. Không thread phụ, không polling: hẹn giờ dùng `SetTimer` mỗi 1 giây chỉ khi đang bật kèm thời lượng.

**Tech Stack:** Rust stable (x86_64-pc-windows-msvc), crate duy nhất `windows-sys`.

**Spec:** `docs/superpowers/specs/2026-11-16-caffein-design.md`

## Global Constraints

- Dependency duy nhất: `windows-sys` (không thêm crate runtime nào khác, kể cả build-dependency).
- Máy không có `rc.exe` → **không dùng file .rc**. Manifest nhúng bằng link arg; icon vẽ bằng GDI lúc chạy.
- Release profile: `opt-level="z"`, `lto=true`, `codegen-units=1`, `panic="abort"`, `strip=true`.
- `#![windows_subsystem = "windows"]` (không console).
- Config: `%APPDATA%\Caffein\config.ini`.
- Autostart: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, value name `Caffein`, data = đường dẫn exe trong dấu ngoặc kép.
- Thời lượng: Vô hạn / 15 phút / 30 phút / 1 giờ / 2 giờ.
- Bật: `ES_CONTINUOUS | ES_SYSTEM_REQUIRED [| ES_DISPLAY_REQUIRED]`; tắt: `ES_CONTINUOUS`.
- Single instance: named mutex `Local\Caffein.SingleInstance`.
- Chuỗi UI bằng tiếng Việt, truyền vào API dạng UTF-16 (hàm `W`).
- Exe phải < 500 KB ở bản release.

## Review Focus

1. **config.ini hỏng/thiếu/key lạ/giá trị rác** → app vẫn chạy với giá trị mặc định, không panic. (Test ở Task 1.)
2. **Explorer restart (taskbar crash)** → icon khay phải hiện lại: xử lý message `RegisterWindowMessageW("TaskbarCreated")`. (Kiểm tra thủ công ở Task 4.)
3. **Đổi "Giữ màn hình sáng" khi đang bật** → cờ execution state cập nhật ngay, không phải tắt rồi bật lại. (Test ở Task 2.)
4. **Exe bị di chuyển sau khi bật autostart** → mỗi lần khởi động, nếu autostart bật thì ghi lại đường dẫn hiện tại. (Task 5.)
5. **Mở Settings hai lần** → chỉ một cửa sổ, lần sau đưa cửa sổ cũ lên trước. (Task 5.)

## File Structure

| File | Trách nhiệm |
|---|---|
| `Cargo.toml` | crate + features `windows-sys` + release profile |
| `build.rs` | nhúng `app.manifest` (comctl v6, DPI aware) qua link arg |
| `app.manifest` | manifest Common Controls v6 + PerMonitorV2 DPI |
| `src/config.rs` | `Config`, `Duration`, parse/serialize INI (thuần), load/save file |

| `src/win.rs` | helper `wide()` (str → UTF-16 NUL) và wrapper `set_execution_state` |
| `src/autostart.rs` | registry Run key: `is_enabled`, `set` |
| `src/icon.rs` | vẽ 2 HICON ly đầy/rỗng bằng GDI |
| `src/tray.rs` | Shell_NotifyIcon add/modify/delete, tooltip, popup menu |
| `src/settings.rs` | cửa sổ Settings (checkbox, combobox, nút Lưu/Hủy) |
| `src/main.rs` | single instance, window ẩn, vòng lặp message, nối các phần |

### Task 2: State + execution state

**Files:**
- Create: `src/state.rs`, `src/win.rs`
- Modify: `src/main.rs` (thêm `mod state; mod win;`)

**Interfaces:**
- Consumes: `config::Duration`
- Produces:
  - `pub const ES_CONTINUOUS: u32 = 0x8000_0000; ES_SYSTEM_REQUIRED = 0x1; ES_DISPLAY_REQUIRED = 0x2;` (ghi giá trị cứng trong `state.rs` để logic không phụ thuộc Win32)
  - `pub struct State { pub active: bool, pub keep_display: bool, pub duration: Duration, deadline_ms: Option<u64> }`
  - `State::new(keep_display: bool, duration: Duration) -> State` (tạo ra ở trạng thái tắt)
  - `activate(&mut self, now_ms: u64)`: đặt deadline = now + phút·60000, hoặc None nếu Vô hạn
  - `deactivate(&mut self)`, `toggle(&mut self, now_ms: u64)`
  - `set_duration(&mut self, d: Duration, now_ms: u64)`: nếu đang bật thì đặt lại deadline tính từ `now`
  - `set_keep_display(&mut self, v: bool)`
  - `tick(&mut self, now_ms: u64) -> bool`: trả về true nếu vừa hết giờ (khi đó tự tắt)
  - `remaining_secs(&self, now_ms: u64) -> Option<u64>`
  - `flags(&self) -> u32`
  - `needs_timer(&self) -> bool` (đang bật và có deadline)
  - `win.rs`: `pub fn wide(s: &str) -> Vec<u16>` (kết thúc bằng NUL), `pub fn set_execution_state(flags: u32)`, `pub fn now_ms() -> u64` (dùng `GetTickCount64`)

- [ ] **Step 1: Viết test trong `src/state.rs`**

```rust
#[test] fn off_flags() { assert_eq!(State::new(true, Duration::Infinite).flags(), ES_CONTINUOUS); }
#[test] fn on_flags_with_and_without_display() {
    let mut s = State::new(true, Duration::Infinite); s.activate(0);
    assert_eq!(s.flags(), ES_CONTINUOUS | ES_SYSTEM_REQUIRED | ES_DISPLAY_REQUIRED);
    s.set_keep_display(false);
    assert_eq!(s.flags(), ES_CONTINUOUS | ES_SYSTEM_REQUIRED);
}
#[test] fn timer_expires() {
    let mut s = State::new(false, Duration::M15); s.activate(1_000);
    assert!(s.needs_timer());
    assert_eq!(s.remaining_secs(1_000), Some(900));
    assert!(!s.tick(1_000 + 899_999));
    assert!(s.tick(1_000 + 900_000));
    assert!(!s.active && !s.needs_timer());
}
#[test] fn infinite_never_expires() {
    let mut s = State::new(false, Duration::Infinite); s.activate(0);
    assert!(!s.needs_timer()); assert!(!s.tick(u64::MAX / 2)); assert!(s.active);
    assert_eq!(s.remaining_secs(5), None);
}
#[test] fn change_duration_while_active_restarts() {
    let mut s = State::new(false, Duration::M15); s.activate(0);
    s.set_duration(Duration::H1, 600_000);
    assert_eq!(s.remaining_secs(600_000), Some(3600));
}
#[test] fn toggle_roundtrip() {
    let mut s = State::new(false, Duration::M30);
    s.toggle(0); assert!(s.active); s.toggle(1); assert!(!s.active);
    assert_eq!(s.remaining_secs(1), None);
}
```

### Task 4: Icon + khay + vòng lặp chính (app chạy được)

**Files:**
- Create: `src/icon.rs`, `src/tray.rs`; Modify: `src/main.rs`

**Interfaces:**
- Consumes: `State`, `Config`, `win::{wide, set_execution_state, now_ms}`, `Duration::{ALL, label}`
- Produces:
  - `icon::make(active: bool) -> HICON`: ly 16×16 nhân theo `GetSystemMetrics(SM_CXSMICON)`, vẽ bằng GDI lên DIB 32-bit có alpha rồi `CreateIconIndirect`. Đầy = thân ly màu nâu cà phê + hơi nóng; rỗng = chỉ có viền.
  - `tray::add(hwnd, icon, tip)`, `tray::update(hwnd, icon, tip)`, `tray::remove(hwnd)`. Callback message `WM_APP + 1`, uID = 1, dùng `NOTIFYICON_VERSION_4`.
  - `tray::show_menu(hwnd, state: &State)`: menu gồm "Bật"/"Tắt" (đổi theo trạng thái), submenu "Thời lượng" với 5 mục radio (`MFT_RADIOCHECK`, đánh dấu mục hiện tại), "Giữ màn hình sáng" (có check), separator, "Cài đặt…", "Thoát". Phải `SetForegroundWindow` trước `TrackPopupMenu`.
  - ID lệnh trong `tray.rs`: `ID_TOGGLE=100`, `ID_DUR_BASE=110` (+ chỉ số trong `ALL`), `ID_DISPLAY=120`, `ID_SETTINGS=130`, `ID_EXIT=140`.
  - Tooltip: đang tắt → "Caffein — Tắt"; bật vô hạn → "Caffein — Đang giữ thức"; có hẹn giờ → "Caffein — Còn 12:34" (định dạng h:mm:ss nếu ≥ 1 giờ).
- `main.rs`:
  - `CreateMutexW` + `GetLastError()==ERROR_ALREADY_EXISTS` → thoát ngay.
  - Tạo cửa sổ message-only ẩn (`HWND_MESSAGE`) có WndProc riêng. Giữ `App { state, config, icons:[HICON;2] }` trong `thread_local! RefCell` (hoặc `static mut` có bọc hàm truy cập).
  - Sau mỗi thay đổi state, gọi `apply()`: `set_execution_state(state.flags())`, cập nhật icon/tooltip, `SetTimer(hwnd, 1, 1000)` nếu `needs_timer()`, ngược lại `KillTimer`.
  - `WM_TIMER` → `tick` → `apply()`. Click trái (`WM_LBUTTONUP` qua callback) → toggle. `WM_CONTEXTMENU`/click phải → `show_menu`. `WM_COMMAND` xử lý các ID; đổi thời lượng/chế độ màn hình từ menu thì cập nhật cả `config` rồi `save()`.
  - Message `TaskbarCreated` → `tray::add` lại.
  - Khi khởi động: `Config::load()`; nếu `activate_on_launch` thì bật luôn. Khi thoát: `tray::remove`, `set_execution_state(ES_CONTINUOUS)`.
  - Mục "Cài đặt…" tạm thời chưa làm gì (Task 5 sẽ nối vào).
